# CodSoft Internship Projects

Three front-end tasks built during my Web Development internship at CodSoft (July 2025), using HTML, CSS and JavaScript.

## Live Demo
- Home: https://nikhilraj7654.github.io/codsoft-internship/
- Task 1, Portfolio: https://nikhilraj7654.github.io/codsoft-internship/portfolio/
- Task 2, Landing Page: https://nikhilraj7654.github.io/codsoft-internship/landing-page/
- Task 3, Calculator: https://nikhilraj7654.github.io/codsoft-internship/calculator/

## Tasks

| Task | Project | What it has |
|------|---------|-------------|
| 1 | Personal Portfolio Website | About, skills, projects, experience, resume download, contact details and footer. Responsive, with light and dark mode. HTML and CSS. |
| 2 | Landing Page | Hero section, resume download, project showcase, contact info and footer. Responsive. Pure HTML and CSS. |
| 3 | Calculator | Add, subtract, multiply, divide, percentage, decimals, AC and DEL. Shows an error on divide by zero and handles invalid input. Dark theme with round buttons. HTML, CSS and JavaScript. |

## What I practised
- Building layouts with Flexbox and CSS Grid
- Making pages responsive for mobile screens
- Handling button clicks with JavaScript
- Updating the page with the DOM
- Handling edge cases in logic (divide by zero, repeated operators)

## Run locally
No installation needed.
1. Download or clone this repository.
2. Open index.html in any browser.

## Folder structure
- portfolio/ : index.html, style.css
- landing-page/ : index.html, style.css
- calculator/ : index.html, style.css, script.js
- resume.pdf : resume used by the Download buttons
- index.html : links to all three tasks
